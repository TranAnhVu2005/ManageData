📁 src/main/java — Code chính của chương trình
Toàn bộ code Java bạn viết đều nằm ở đây
Maven mặc định tìm source code tại thư mục này

📁 config/
Chứa DBConnection.java
Nhiệm vụ duy nhất: tạo kết nối tới MySQL

Các tầng khác (DAO, Service) gọi vào đây
để lấy Connection, không tự kết nối DB

📁 model/
Ánh xạ dữ liệu từ DB sang Java

Ví dụ bảng USERACCOUNTS có các cột:
userID | userName | ID | passWordHash | ...

→ User.java có các field tương ứng:
private String userID;
private String userName;
private String ID;
private String passWordHash;

Chỉ có field + getter + setter
KHÔNG chứa logic, KHÔNG kết nối DB

📁 dao/
DAO = Data Access Object

Tầng duy nhất được phép gọi stored procedure
Mỗi method trong DAO = 1 stored procedure

Ví dụ UserDAO.java:
updateInfo()       → gọi procedure updateInfo
transferMoney()    → gọi procedure transferMoney
checkTransaction() → gọi procedure checkTransaction
deleteAccount()    → gọi procedure deleteAccount

Nhận kết quả từ DB → trả về model hoặc String
KHÔNG xử lý logic nghiệp vụ
KHÔNG hiển thị giao diện

📁 service/
Tầng xử lý logic TRƯỚC khi gọi DAO

Ví dụ UserService.java:

Khi người dùng đổi password:
1. Nhận password dạng plain text từ View
2. Hash password → SHA256           ← xử lý ở đây
3. Gọi UserDAO.updateInfo(...)      ← mới gọi DAO
4. Trả kết quả về View

Nếu không có Service:
View gọi thẳng DAO → khó test, khó bảo trì

📁 view/
Giao diện người dùng

Hiển thị menu, nhận input từ bàn phím
Gọi Service để xử lý
Hiển thị kết quả

Ví dụ TransferView.java:
1. Hiển thị "Nhập số tài khoản nguồn: "
2. Đọc input từ Scanner
3. Gọi UserService.transferMoney(...)
4. Hiển thị kết quả "Chuyển tiền thành công"

KHÔNG gọi DAO trực tiếp
KHÔNG xử lý logic

📁 util/
Các hàm tiện ích dùng chung giữa 2 người

HashUtil.java
→ hash password, PIN trước khi lưu DB
→ Ví dụ: SHA2("password123") → "a665a45..."

Validator.java
→ Kiểm tra input hợp lệ trước khi xử lý
→ Ví dụ: số điện thoại đúng 10 số không?
         số tiền có > 0 không?
         email đúng định dạng không?

📁 src/main/resources/
Chứa các file cấu hình, KHÔNG phải code Java

config.properties
→ Thông tin kết nối DB
→ Mỗi người tự điền theo máy mình
→ Không commit lên Git

Maven tự động đưa thư mục này vào classpath
→ Đọc file bằng getResourceAsStream()


📁 src/test/java/
Chứa code test

Viết test để kiểm tra từng method hoạt động đúng
Ví dụ AccountDAOTest.java:
→ Test createUserAccount() có tạo được user không
→ Test withdrawMoney() có trừ đúng số tiền không

Tách riêng khỏi code chính
→ Chạy test không ảnh hưởng DB thật

📁 sql/
Chứa toàn bộ script SQL

Đánh số thứ tự để chạy đúng thứ tự:
01_schema.sql      → tạo bảng (chạy đầu tiên)
02_data.sql        → dữ liệu mẫu
03_procedures.sql  → Task 1-8
04_triggers.sql    → triggers
05_functions.sql   → random_string

Không phải code Java, Maven không đụng tới

📁 docs/
Tài liệu đồ án

ERD.png      → sơ đồ E-R
BaoCao.docx  → báo cáo nộp thầy

Không ảnh hưởng gì đến code

pom.xml
File quan trọng nhất của Maven

Khai báo:
→ Tên project
→ Thư viện cần dùng (MySQL Connector JAR)
→ Phiên bản Java

Maven đọc file này → tự download JAR về
→ 2 người cùng pom.xml → cùng thư viện
→ Không cần copy JAR thủ công

Main.java
Điểm khởi chạy duy nhất

JVM chạy method main() trong file này
→ Gọi LoginView để hiển thị màn hình đầu tiên
→ Mọi thứ còn lại tự động chạy theo luồng
